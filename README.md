# Wizzie Farm

A wizard adventure made for fun (never sold).

## ▶ Play now, in your browser (Windows or Mac)

**https://jorgelgomezjr.github.io/wizzie-farm/play/**

One click, nothing to install. Use Google Chrome or Microsoft Edge (Safari is not supported).
Your wizard is saved in that browser; use Menu → Export this wizard to back it up.

**Play together:** one player clicks Realm → Host and shares the lantern sigil (join code);
the others click Realm → Join and type it in. Up to 3 wizards. Everyone must be on the same version.

## Windows desktop app

The desktop app updates itself from this repository (`latest.json` + `updates/`).
Current game version: **2.1.0 "New Faces"**.
Offline update: put `updates/wizzie-farm-game-<version>.zip` (and its `.sha256`) in
`Documents\Wizzie farm\updates` and start the game.
